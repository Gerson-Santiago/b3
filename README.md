# Dashboard de Investimentos B3

Dashboard interativo desenvolvido em Python com Streamlit para visualização e análise de relatórios e movimentações exportados da **B3 (Área do Investidor)**.

---

## 🚀 Como executar

### 1. Instalar as dependências
```bash
pip install -r requirements.txt
```

### 2. Iniciar a aplicação
```bash
streamlit run dashboard/app.py
```

---

## 📂 Como usar

1. Ao abrir o painel no navegador, use o menu lateral para fazer o upload do seu extrato/relatório exportado da B3 (`.csv` ou `.xlsx`).
2. Alternativamente, você pode salvar o arquivo `.csv` diretamente na pasta `csv/` ou raiz do projeto.
3. Visualize os gráficos de carteira, proventos (dividendos/JCP), evolução patrimonial e métricas de desempenho.
